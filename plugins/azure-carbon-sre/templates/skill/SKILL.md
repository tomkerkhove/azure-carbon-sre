# Skill title

## Scope

State the service, resource types, and environments this procedure applies to.

## Safety

- Start with read-only discovery.
- Require explicit confirmation before any state-changing action.
- Document impact, blast radius, verification, and rollback.

## Procedure

1. Identify the target and time range.
2. Collect the minimum evidence needed to confirm the condition.
3. Correlate at least two independent evidence sources before declaring root cause.
4. Apply a reversible mitigation only when authorized.
5. Verify the expected recovery signal and document remaining uncertainty.
